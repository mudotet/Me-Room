# Shared Contract Guidelines

This directory is shared by the backend, mobile app, and native 3D teams.
Read `README.md` here before changing `example.json` or adding schema definitions.
The example is synthetic draft data, not an implemented or versioned API guarantee.
Assign one writer for contract changes and notify all three leads before changing field names, units, origins, or model identifiers.
Update affected producers, consumers, fixtures, and documentation together when a contract change is authorized.
Validate JSON syntax and scene dimensions, and never add private scan data or credentials.
