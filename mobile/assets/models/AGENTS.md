# Model Asset Ownership

The native 3D team owns this directory.
Read repository-root `mobile/components/Room3D/AGENTS.md` and its `.codex/TEAM.md` before changing assets.
Map agreed `modelId` values to bundled GLB files and document model dimensions, orientation, origin, and permitted usage when adding them.
Use licensed or authorized assets, and verify textures and loading on the demo iPhone.
Coordinate Metro configuration and dependency changes with the mobile app lead.
No GLB files exist yet; the shared example's model IDs currently require box fallbacks.
